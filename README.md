# Sysmac-Studio-8-AI-Adaptive-Controller
OMRON Sysmac Structured Text (IEC 61131-3) program — an 8-model AI-blended adaptive controller (Liquid NN, KAN, Mamba, Koopman, Transformer, PINN, Diffusion Policy, MoE Gate) fused with an AIMD PI controller and RL-style reward shaping, for setpoint tracking with auto K/T identification.
